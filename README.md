# tutorlawrence.com

The website for Tutor Lawrence: one-to-one English lessons online (Business English, IELTS and ECL exam preparation).

## How it is put together

A small static site. There is no framework and nothing to install.

```
site.json            Facts used across the site: prices, package contents, lesson counts, booking link
build.py             Builds the site from src/ into public/
src/layout.html      The header, footer and <head> shared by every page
src/pages/*.html     One file per page (the part between header and footer)
src/assets/          Stylesheet, script, fonts and images
src/static/          Files copied to the site unchanged
firebase.json        Hosting settings: clean addresses, redirects, caching
.github/workflows/   Automatic publishing (see below)
```

To change a price, a package or the lesson count, edit `site.json`. Every page picks it up.

## Building locally

```bash
python3 build.py
```

The finished site is written to `public/`. That folder is generated, so it is not kept in git.

## Publishing

Hosting is Firebase Hosting, project `tutorlawrencelanding`.

- **Any branch other than `main`** is published to a preview address. The address is shown in the summary of the "Deploy preview" run under the Actions tab. Previews expire after 30 days.
- **`main`** is published to the live site.

So the routine is: make the change on a branch, check the preview, then merge into `main`.
